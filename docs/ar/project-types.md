# أي نوع من المشاريع

القواعد تخص التسليم وليس ما تبنيه. اختر الصف الأقرب لمشروعك.

| ما تبنيه | النمط | بوابات التقنية التي ستستخدمها | وأيضًا مفيد |
|---|---|---|---|
| تطبيق SaaS أو ويب | `standard` | `Next.js` و`React` و`Laravel` و`Django` و`Rails` و`.NET` | فحص الحزمة، وفحص الترحيلات |
| متجر إلكتروني أو سوق | `standard` أو `strict` | كما سبق | [وحدة المجال](../../skills/engineering-rules-ar/references/domain-optional.md) إن كان عندك موقع جغرافي أو مناطق أو مطابقة بين طرفين |
| تطبيق موبايل | `standard` | `React Native` و`Expo` و`Flutter` | فحص مفاتيح التوقيع والروابط غير المشفّرة، ونسخ اختبار عند الطلب |
| واجهة REST أو GraphQL | `standard` | `.NET` و`Node` و`Go` و`Java` و`Python` و`Rust` و`PHP` | `audit`، ومراجعة المخطط أو الترحيلات |
| مكتبة أو SDK أو أداة طرفية | `strict` | محرك لغتك | سياسة ملف القفل، و`audit`، وأرقام إصدارات دلالية |
| أداة داخلية أو مجموعة سكربتات | `lite` | ما تستخدمه | فحص الأسرار، والاختبارات |
| موقع محتوى أو تسويق | `lite` | `Node` (مولّدات المواقع الثابتة) | فحص الوثائق، وفحص الروابط |
| خادم ألعاب أو واجهة لحظية | `standard` | `Go` و`Rust` و`.NET` و`Node` | خطة الاستمرارية، واختبارات الحمل (لديك) |
| مشروع بيانات أو تعلم آلي | `standard` | `Python` | متطلبات مثبّتة، و`pip-audit`، واستثناء الدفاتر بـ `STACK_EXCLUDE` |
| بنية تحتية كود (IaC) وصور حاويات | `standard` | `Terraform` و`OpenTofu` و`Docker` | قواعد `tflint` و`trivy` و`hadolint` |
| مستودع كبير يجمع عدة مما سبق | لكل مشروع | كل ما يُكتشف | ملف `AGENTS.md` واحد للمستودع كله |

## ما لا يعتمد على فكرتك

طلبات دمج صغيرة، أسرار خارج Git، إعدادات كبيانات، وثائق مع الكود، أعلام ميزات تنتهي، اعتمادات مثبّتة، حالة صادقة، والإنسان يدمج.

## ما يعتمد عليها

أضف قواعد لمجالك كقسم مرقّم في `AGENTS.md` (مثل المدفوعات، أو البيانات الصحية، أو بيانات الأطفال). كل قاعدة جديدة تأخذ صفًا في `docs/rules-compliance.md` بحالة صادقة، وسجل قرار (ADR).
