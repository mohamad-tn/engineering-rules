# Onboarding

1. Clone the repository and install the local hooks: `pre-commit install`.
2. Read `AGENTS.md`. It is short.
3. Run the gates locally: `bash .github/scripts/local-proof.sh`.
4. Pick a task, open a pull request of about 400 lines or fewer, and fill in the template.

Fill in: how to install the toolchain, how to run the app, who to ask.
